# Kimi 限额评测协议 · 2026-10-03

用户说明可用免费额度为1,000,000 Token。当前配置为百炼 `kimi-k3`，同一服务、模型及采样参数用于单/多Agent。平台实际余额不可从本地配置核实，不开启付费设置；平台的“免费额度用完即停”仍是避免额外计费的保障。

## 预算与顺序

- 计划12个既有合成场景，每组各一次，共24次，不运行原72次重复试验。
- 已完成工具调用及结果回传诊断，返回用量535 Token，计入本轮总预算。
- 总准入预算750,000已返回Token；每次任务开始前须还能容纳完整60,000 Token任务预算。单次响应及并发调用可能越过任务软限，未返回的服务计费用量不可见。因此这不是平台计费硬上限，预留约250,000 Token。
- 先运行 `access-approved` 的单/多Agent两次，完整流程通过后运行其余11个场景22次。这两次属于本轮24次，不重复跑入门题，也不筛选替换失败。
- 如果准入预算不足或模型认证/请求错误，停止且保存不完整结果。连续三个模型连接、限流、服务异常或请求超时也停止；正常工作流失败仍保留并继续其他场景。
- 每任务30次逻辑模型调用、60,000 Token、300秒跨模拟审批阶段总时限；温度0、推理强度low、单次输出上限4096 Token、请求超时180秒，客户端最多一次重试。
- 任务串行，子Agent内部仍可并行。每次使用临时SQLite库，审批批准/拒绝由脚本模拟，不操作网页工单。
